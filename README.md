# Butterplan

Meal-Prep-Wochenplan mit Einkaufsliste, gebaut für das iPhone als Home-Bildschirm-App.

## Online stellen mit GitHub Pages

1. Konto auf github.com anlegen (kostenlos).
2. Oben rechts auf **+** → **New repository**. Name: `butterplan`, Sichtbarkeit **Public**, dann **Create repository**.
3. Auf der neuen Seite den Link **uploading an existing file** antippen.
4. Die Dateien aus diesem Ordner hineinziehen (nicht den Ordner selbst): `index.html`, `manifest.webmanifest`, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png`. Unten auf **Commit changes**.
5. Im Repository **Settings** → links **Pages**. Bei *Source* „Deploy from a branch“ wählen, Branch **main** und Ordner **/ (root)**, dann **Save**.
6. 1–2 Minuten warten. Die Adresse lautet `https://DEIN-NAME.github.io/butterplan/` und steht oben auf der Pages-Seite.

## Auf das iPhone

1. Die Adresse in **Safari** öffnen (nicht in Chrome).
2. Unten auf das **Teilen**-Symbol → **Zum Home-Bildschirm** → **Hinzufügen**.
3. Butterplan ab jetzt immer über das Icon öffnen. Die App startet dann im Vollbild.

## Gut zu wissen

- Jeder Plan wird auf dem jeweiligen Gerät gespeichert. Zwei iPhones haben zwei getrennte Pläne.
- Wird die App vom Home-Bildschirm gelöscht, sind auch ihre Daten weg.
- Updates: neue `index.html` im Repository über **Add file → Upload files** ersetzen. Die gespeicherten Pläne bleiben erhalten.
